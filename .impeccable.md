## Design Context

### Users

Skill Bridge serves VS Code users who manage AI agent skill folders but may not be comfortable with Git CLI workflows. Their primary job is to safely send skills from Workspace to Central, bring reusable skills back to Workspace, and manage workflow groups without losing files.

### Brand Personality

Calm, trustworthy, and practical. The interface should feel like a native VS Code tool that makes consequential file operations understandable rather than decorative or playful.

### Aesthetic Direction

Follow the active VS Code light, dark, or high-contrast theme. Use semantic VS Code color tokens and reserve emphasis for the current primary action, selection, warnings, and errors. Avoid independent accent palettes, gradients, and competing primary buttons.

### Design Principles

- Make the Workspace → Central and Central → Workspace direction explicit before every transfer.
- Keep one primary call to action in each visible task area; move advanced actions behind progressive disclosure.
- Preserve core actions in narrow Webview panels and reflow controls before relying on horizontal scrolling.
- Communicate state with labels and structure as well as color.
- Keep Context Menus fast and focused; use Webviews for comparison, multi-selection, and review.
